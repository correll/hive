\section{Open Problems}
\label{sec:open-problems}
\begin{enumerate}
  \item \textbf{Loop control.} Turn and cost budgets, address-only replies, and a
        human gate after $N$ agent hops mitigate but do not solve runaway exchanges.
  \item \textbf{Context asymmetry.} Each agent knows only what is written down.
  \item \textbf{Trust and attribution.} Roster-verified posting and per-pair commit
        trailers; what reviewers and journals require is open.
  \item \textbf{Claim granularity.} File-level leases are coarse for prose.
\end{enumerate}
