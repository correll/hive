# Decisions

don't share context. Add `NNNN-slug.md`; never rewrite an accepted record,
supersede it with a new one (`Supersedes: 0002`).

Format: Status · Context · Decision · Consequences. Write down anything another
participant's agent would otherwise have to rediscover. What *must* be written
down is open problem #2 in AGENTS.md.
